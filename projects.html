System Design Decisions & Trade-offs

Architecture Choices Across Shipped Builds
Decision 01 · Resume Extraction & ARC

Typed Pydantic Contracts Over Free-Form JSON Prompts

Prompting an LLM to "return valid JSON" breaks downstream parsers when nested fields drift. Pairing Groq low-latency inference with Instructor and strict Pydantic schemas enforces exact types, reading order, and structured retry correction before responses reach the FastAPI layer.

PyMuPDF · Groq API · Instructor · Pydantic
Decision 02 · Multi-Document RAG Assistant

Combined Rubric + N-Gram Eval Harness

Single-score evaluation misses subtle citation drift in multi-document RAG. Combining retrieved-context grounding and embedding similarity with BLEU, ROUGE, and LLM-as-a-Judge test scenarios captures both semantic faithfulness and exact factual overlap before Docker deployment.

Vector Search · LLM-as-a-Judge · BLEU · ROUGE
Decision 03 · Documint ERP

Database-Layer Multi-Tenant RBAC via PostgreSQL RLS

Instead of relying solely on frontend route guards between Admin and Employee portals, Documint ERP enforces row isolation inside Supabase PostgreSQL Row Level Security (RLS) and PLpgSQL policies so tenant boundaries hold regardless of client state.

Supabase · PostgreSQL RLS · TypeScript · Bun
Decision 04 · Review Intelligence & Churn ML

Statistical Feature Pruning & Duplicate-Safe Ingestion

Rather than feeding raw noisy tables directly into complex models, Telecom Churn combines Chi-square, RFE, and ANOVA F-tests before stacking classification, while First Quadrant Labs' review pipeline validates CSV schemas and deduplicates before persisting reusable model artifacts.

Scikit-Learn · Pandas · Feature Selection · CSV Validation
