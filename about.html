About Me

Generative AI Engineer and Python/Django Developer building grounded LLM systems, multi-step agentic workflows, and measurable backend software.

I am a Generative AI and software engineer based in Kollam, Kerala, India, holding a Master of Computer Applications (MCA) from Kerala University (2022–2024, 7.68 CGPA). My objective is to build production-oriented Generative AI solutions where prompt design, retrieved context, structured Pydantic/JSON schemas, SQL checks, and automated validation work together seamlessly.

Engineering Philosophy

01. Grounded Generation Over Guesswork: Rather than relying on unverified prompts, I anchor LLM responses in retrieved document chunks, embeddings, and strict schema enforcement (Instructor + Pydantic) so downstream systems receive predictable outputs.

02. Evaluation Built Into Delivery: At Ladder7 Nextstep Solutions, I designed evaluation scenarios combining LLM-as-a-Judge checks with embedding similarity, BLEU, and ROUGE to catch hallucinations before deployment.

03. Reliability Across Backend & SQL: From Django REST APIs and SQL consistency tests in Dubai to PostgreSQL Row Level Security in Documint ERP, I verify data integrity, failure handling, and input validation end to end.
